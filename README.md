# Barbalho Contabilidade — portal e automação

Protótipo estático, zero dependências. Inclui rebranding baseado no Instagram/site público da Barbalho, preview do portal do cliente, seleção local de documentos, status de fluxo, automações e CTAs para WhatsApp.

## Rodar

```powershell
python -m http.server 4175 --bind 127.0.0.1
```

Abra `http://127.0.0.1:4175/`.

O login, envio e formulário são somente demonstração visual. Não existe backend nem transmissão de arquivos nesta versão.
