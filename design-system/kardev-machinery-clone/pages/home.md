# Home page override — Barbalho Contabilidade

Source direction is based on the public Barbalho Contabilidade Instagram and official site reviewed on 2026-09-26.

- Product: consultive accounting website with client portal, document intake and automation.
- Tone: strategic, practical, trustworthy, close to the entrepreneur.
- Colors: deep navy `#101522`, electric blue `#2b5bff`, cyan `#23d5e6`, signal yellow `#ffd21a`, paper `#f7f9fd`, ink `#15213a`.
- Typography: local Maven Pro assets, with bold display hierarchy and short readable paragraphs.
- Layout: preserve the source clone geometry — fixed language strip + navbar, split hero carousel, counter/about block, image-led card carousels, news/content block and multi-column footer.
- Motion: preserve source-style hero autoplay, previous/next controls, hidden-on-scroll header, smooth anchors and IntersectionObserver reveal. Disable non-essential motion under reduced motion.
- Imagery: use Barbalho-branded business/portal visuals in the same navy/blue/cyan/yellow language; do not replace the source layout with a generic SaaS landing page.
- UX: portal CTA opens a demo login modal; file picker validates allowed extensions and 10 MB limit locally; status messages explain that no data leaves the browser.
- Accessibility: labels are explicit, status uses `role=status`, focus rings stay visible, icon-like controls have text labels, touch targets are at least 44px, and reduced motion is respected.
- Keep the source layout and interaction model, but replace the old Kardev black/orange industrial palette and Turkish copy with Barbalho branding and Portuguese content.
